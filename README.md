### ⚡ Production Deployment & Latency Optimization Notes

* **Vercel Function Region**: By default, Vercel runs Serverless Functions in Washington D.C., USA (`iad1`). Since our Supabase database is hosted in Singapore (`ap-southeast-1`), this adds ~250ms of network overhead per query. **You must change your Vercel Function Region to Singapore (`sin1`)** in *Settings ➔ Functions ➔ Function Region* and redeploy to keep query latency under **5ms**.
* **Environment Variables**: Make sure to add all keys from `.env.example` to Vercel's Environment Variables panel before building. Next.js dynamic page pre-rendering will fail at build-time if it cannot establish a connection to your Supabase instance.
